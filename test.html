Set up the secure address

  1. On the Mac mini, put make_cert.sh in ~/TempestLogger with the server, then in Terminal run bash ~/TempestLogger/make_cert.sh and restart the server.
  2. At home, on this device, tap Install certificate below and choose Allow.
  3. Open Settings, tap Profile Downloaded near the top, then Install.
  4. In Settings › General › About › Certificate Trust Settings, turn on Amankenzie Station (home network only).
  5. Come back here and tap ↻.
Do steps 2–5 once on the iPad and once on the iPhone. The certificate only works for home-network addresses, so it can't vouch for any real website.
